# First Trio Example

This example is structurally based on the first complete trio in the current
external KGA pedigree draft on July 29, 2026, but the committed sample names are
generic role-based placeholders.

It is intended as a concrete manifest-mode example for the standalone
`preflight/` workflow.

Before running, replace the placeholder `vcf_path` values in
`sample_manifest.tsv`
with real single-sample VCF paths.
